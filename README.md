# DEEPNDANCE

## DEEPNDANCE is born here and now.

**September 9, 2026**

DEEPNDANCE is a new vision of electronic music conceived and created by **Noah Fex**.

It begins where **depth, movement, energy and the unexpected** meet.

DEEPNDANCE is not simply Deep House, Dance, Techno, Trance or Progressive music.

It can take elements from all of them while exploring something different.

Its philosophy is built around four principles:

**GO DEEP.**  
**CREATE MOVEMENT.**  
**BREAK EXPECTATION.**  
**MAKE PEOPLE FEEL SOMETHING.**

DEEPNDANCE combines deep emotional atmospheres, powerful low frequencies, energetic rhythms and unconventional sound design.

Every DEEPNDANCE track should contain something unexpected — a sound, rhythm, texture, silence, voice or sonic event capable of breaking expectation.

This repository contains the original **DEEPNDANCE Manifesto — Version 1.0**.
